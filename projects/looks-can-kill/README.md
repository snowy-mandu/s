# IVE — Looks Can Kill 모션그래픽 (팬 작업, 20초)

틀: M45 응용(줄마다 소품 하나 + 매치 컷 + 2–3색 + 잔무늬). 성격: 빠른 편집형. 영상 소재 없이 글자·도형만 씀(합성 일체감 확인 목록 첫 줄).

**형식 아이디어: 시선이 곧 컷이다.** 눈이 한 번 볼 때마다 시선 광선이 화면을 베고, 그 베인 선이 다음 장면으로 넘어가는 전환이 된다.
MV 서사 장치(촬영장에서 히어로를 "연기하는" 스타 → 진짜 히어로)와 곡 시놉시스("등장하는 순간 승부가 끝난다")를 같이 담았다.
로고의 두 O는 직접 그린 칼날 블록체의 눈이다.

첫 1초: 검은 화면의 감긴 눈이 뜨고 → 오른쪽을 보고 → 그 시선이 화면을 벤다.

| 초 | 장면 | 색 | 전환 | 강약 |
|---|---|---|---|---|
| 0–1 | 감긴 눈이 뜨고 오른쪽을 본다 | 검정·미색·빨강 | 시선이 화면을 벤다 | 도입 |
| 1–3.5 | 촬영장 슬레이트: SCENE 01 / TAKE 01 / ROLE GIRL HERO 타자 → 2.5초에 딱 | 미색·검정·빨강 | 슬레이트가 아래로 퇴장 | 유지 → 연타 |
| 3–4 | ACTION → 시선 한 번에 베이고 → 밑에 있던 CUT, "TAKE 01 — OK" | 미색·검정 | C의 획 속으로 줌 → 검정 | 펀치라인 1 |
| 4–6 | 칼날 글자 LOOKS가 8분음표마다 착지, O 두 개가 눈으로 뜸, 좌·우 시선 | 검정·미색·빨강 | 로고가 위로 올라가 HUD 제목이 됨 | 연타 |
| 6–7.9 | 격투 게임 HUD: ROUND 1 → FIGHT → 시선 → 상대 체력 0 → K.O. (타이머 99 그대로, TIME 0.01 SEC) | 같음 | 시선 베기 | 펀치라인 2 |
| 8–9.5 | 코믹 칸 6개에 눈 6개(버스트) → 모두 한가운데를 봄 → 여섯 시선이 모임 | 코발트·미색·빨강 | 흰 별이 화면을 덮음 | 쌓기 |
| 9.6–11.6 | 별이 A의 속공간으로 수축 → CAN (굵기 훑기), ONE LOOK IS ALL IT TAKES | 코발트·미색·빨강 | 라이저 | 상승 |
| 11.6–12 | 완전한 정지 0.4초: 검정 + 빨간 점 하나, 무음 | | 하드 컷 | 쉼표 |
| 12–14 | 드롭. 화면만 한 KILL, 박자마다 시선이 글자를 벤다(3번) | 빨강·검정 | 하드 컷 반전 | 절정 |
| 14–16 | KILL 다섯 줄이 엇갈려 흐름(가운데만 빨강) → 한 줄로 모여 선 | 검정·빨강 | 선 = 눈꺼풀 | 절정 유지 |
| 16–18.5 | 눈 모양 조리개가 열리며 LOOKS can KILL 로고 조립, 좌·우·정면 응시 | 검정·미색·빨강 | 홍채가 화면을 채움 | 해결 |
| 18.5–20 | 섬광 → 큰 눈이 정면을 보다 감는다 = 첫 프레임 | | 루프 | 마무리 |

화면 글자는 곡 제목과 직접 쓴 카피만 쓴다(가사 인용 없음). 소리는 `synth.py`가 코드로 합성한 120 BPM 원곡 대체 음악이다(원곡 음원은 쓰지 않음).

## 렌더
```
npm i playwright-core @fontsource/anton @fontsource/instrument-serif @fontsource/black-han-sans
python3 synth.py && ffmpeg -i score.wav -af "acompressor=threshold=-14dB:ratio=3:attack=5:release=80,loudnorm=I=-14:TP=-2.5:LRA=9,alimiter=limit=0.75:level=false" score_m.wav
node render.js still 0,1.1,3.6,7.1,9.9,12.7,14.6,17.7 stills   # 스틸
node render.js full lck.mp4 score_m.wav 3                      # 본 렌더(서브프레임 3장 모션 블러), 약 13분
```
